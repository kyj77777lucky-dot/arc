# 📈 관심종목 시세판

관심 있는 미국주식의 **현재가, 오늘 등락률, 52주 최고가·최저가**를 한 화면에 보여주는 프로그램입니다.

```
종목    현재가($)  전일대비   등락률   52주 최저  52주 위치   52주 최고 고점대비
AAPL       404.72 ▲    6.06   +1.52%      372.98  ──●───────     533.73   -24.2%
NVDA       123.09 ▼    4.91   -3.83%       84.53  ───────●──     134.76    -8.7%
```
(위 숫자는 예시입니다.)

## 처음 한 번만: 준비하기

1. 파이썬을 설치합니다. https://www.python.org/downloads/
   (윈도우에서는 설치 화면의 **"Add Python to PATH"를 꼭 체크**하세요.)
2. 이 폴더에서 터미널을 열고 필요한 라이브러리를 설치합니다.
   ```
   pip install -r requirements.txt
   ```

## 실행하기

```
python watchlist.py
```
`watchlist.txt`에 적힌 종목을 조회합니다. (맥에서는 `python` 대신 `python3`)

| 하고 싶은 것 | 명령어 |
|---|---|
| 내 관심종목 보기 | `python watchlist.py` |
| 원하는 종목만 바로 보기 | `python watchlist.py AAPL KO` |
| 인터넷 없이 연습하기 (가짜 데이터) | `python watchlist.py --demo` |

## 관심종목 바꾸기

`watchlist.txt`를 메모장으로 열어 **한 줄에 티커 하나씩** 적으면 됩니다. `#` 뒤에는 메모를 남길 수 있어요.
```
AAPL   # 애플
KO     # 코카콜라
```
티커를 모르면 구글에 "회사이름 티커"로 검색하세요. (예: "코카콜라 티커" → KO)

## 화면 읽는 법

- **등락률**: 직전 거래일 종가와 비교해 몇 % 올랐는지/내렸는지. 한국식으로 **빨강=상승, 파랑=하락**
- **52주 위치**: 최근 1년 동안의 최저가(왼쪽 끝)와 최고가(오른쪽 끝) 사이에서 지금 가격이 어디쯤인지 `●`로 표시
- **고점대비**: 1년 중 가장 비쌌던 때보다 지금 몇 % 낮은지
